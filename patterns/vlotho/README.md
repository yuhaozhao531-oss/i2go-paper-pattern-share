## 用途与边界

VLOTHO 的说明写得很清楚：这些是**几何原型 / trial patterns**，不是商业纸格，缝制前必须做纸样或便宜材料的 mock-up；缝份、刀口、材料厚度和装配方式要按实际材料调整。

因此：

- ✅ 可以用于内部管线验证：导入 SVG/DXF、核对片数/尺寸、演示「纸格 → 3D」流程。
- ❌ 不能当作 i2GO 背包/铅笔袋的生产纸格。
- ❌ 不能直接商用或再分发为商业纸格；如需商用，先向 VLOTHO 确认授权。
- ❌ 不能拿它冒充客户的产品纸格。

真正的 i2GO 工业版，仍然需要客户自己的纸格 / DXF + 材料五金规格 + 版师签核。
